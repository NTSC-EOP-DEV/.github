# NTSC-EOP-GROUP

中国科学院国家授时中心**EOP组**（NTSC-EOP-GROUP）。

面向地球定向参数（Earth Orientation Parameters, EOP）的测量与服务、VLBI科学与技术、空间大地测量研究，开展数据方法、软件开发、科研教学。

## 研究课题

- **VLBI 世界时（UT1）测定**：VLBI 观测数据处理与 UT1 高精度确定
- **EOP 融合与预报**：地球定向参数的融合与预报算法
- **地球自转变化动力学机制**：地球自转变化背后的地球动力学机制研究
- **脉冲星VLBI观测**：脉冲星的VLBI观测，时间尺度、时间同步
